# Landing page (/)

Mode: Persuade. Audience: developers and small teams who self-host, already hold a model API key, care about cost. Action: copy the one-line install. Proof: a replayed real run ending in a PR, the spend meter tripping its hard stop, where everything runs (your VM), the harness switch. Must not feel: generic AI-startup, 3D as decoration, dark terminal, corporate SaaS grid.

## Direction contract

THESIS: Your VM is your observing station and every run is a classified, logged observation. Refuses the category default of a near-black terminal hero with a feature-card grid.

OWN-WORLD: Committed atlas cobalt (#1F3F8C) owns whole regions. Plates are cool chalk (#E9EEF4) with numbered plate frames and hairline rules. Nimbus slate (#53627A) carries secondary text, and sunlit-cumulus rose (#E8B9A6) is the only warmth. International orange (#FF5A1F) appears only on pressable things. Storm red (#C2231B), the maritime storm-warning flag, marks only the 100% hard-stop state: the product's one danger signal must not share rose with the 80% warning. Archivo Expanded caps set plate headings, Latin genus names are in Bodoni Moda italic, data is in Geist Mono, and UI copy is in Geist. Run progress is drawn as WMO sky-cover oktas; spend is a barometer reading Fair, Change, Storm.

STORY: The visitor sees an agent work unattended and end in a PR, sees that it runs on a VM they own with their own keys, sees that the limit actually stops spend, then copies the install.

FIRST VIEWPORT: The cobalt field fills the screen. Left: the wordmark, a plain headline ("Coding agents on a server you already own."), the install card with an orange copy button, and a GitHub link. Right, about 55% of the width: Plate I, a live WebGL cumulus whose tower rises with each event of a replayed run, logged as courses beneath it (a full-width log keeps each course on one line; a narrow column beside the cloud wraps every event). It ends with the PR opened, and a barometer reading the run's cost.

FORM: Candidate 7 of 7 (International Cloud Atlas), seed a4646c01. Signature interaction: the run replay drives the cloud's growth and the barometer needle. The harness switch reclassifies the plate's genus. Motion: slow condensation, a hard state ink on completion, and a descent on scroll through high, middle and low cloud to the station.

Raises: banded courses (from the clay tower), altitude-tier descent (from the cel dawn), form equals record (from HyperCard), hard two-state states (from the cabaret), orange for action only (from the warm app).

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
